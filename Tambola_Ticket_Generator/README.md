# Tambola Ticket Generator

This project generates a standard 3 × 9 Tambola ticket using Python.

The program randomly selects valid numbers for each column, ensures that every row contains five numbers, and displays the generated ticket as an image using Matplotlib.

## Features

- Automatic Tambola ticket generation
- 3 × 9 ticket format
- Five numbers in each row
- Column-wise number ranges
- Random number selection
- Numbers arranged in ascending order within each column
- Ticket visualization using Matplotlib

## Technologies Used

- Python
- NumPy
- Matplotlib

## Tambola Number Ranges

| Column | Number Range |
|---|---|
| 1 | 1–9 |
| 2 | 10–19 |
| 3 | 20–29 |
| 4 | 30–39 |
| 5 | 40–49 |
| 6 | 50–59 |
| 7 | 60–69 |
| 8 | 70–79 |
